# 📱 Mobile Sales Dashboard | Power BI

## 📌 Project Overview

This project focuses on developing an interactive
Mobile Sales Dashboard using Microsoft Power BI.

The dashboard provides insights into mobile sales
performance, key business metrics, transaction trends,
and sales comparisons across different time periods.

The objective is to transform sales data into
actionable business insights through data visualization
and interactive reporting.

---

## 🛠️ Tools & Technologies

- Microsoft Power BI
- Power Query
- DAX
- Data Modeling
- Data Visualization

---

## 📊 Key Performance Indicators (KPIs)

- Total Sales
- Total Quantity Sold
- Total Transactions
- Average Price
- Year-over-Year Sales Comparison

---

## 📈 Dashboard Features

- Interactive sales performance analysis
- KPI cards for business metrics
- Time-based sales comparisons
- Product and payment-related filtering
- Interactive visualizations
- Business performance monitoring

---

## 🔍 Key Business Questions

1. What is the total sales revenue?
2. How many mobile units were sold?
3. What is the average selling price?
4. How do sales compare across different periods?
5. How can interactive dashboards support
   business decision-making?

---

## 🧮 Data Analysis

The dashboard uses Power BI features such as:

- Data transformation using Power Query
- Calculated measures using DAX
- Interactive filtering
- KPI visualization
- Time-based performance analysis
